Bring your own Grafana

The landing page deliberately stays static. Every embed slot stores its latest URL inside localStorage so you can configure it per environment without redeploying the binary.

  1. Open your Grafana dashboard ➝ Share ➝ Embed and copy the direct panel URL.
  2. Paste it into a slot above and click Embed. The iframe swaps immediately.
  3. Use Reset to jump back to the baked-in defaults.

Tip: append &theme=light&refresh=10s to the Grafana URL if you want it to match this page.
