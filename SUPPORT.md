# Support

WolveKafka is early-stage open source software maintained on a best-effort
basis. There is no guaranteed response time, production SLA, or paid support
channel associated with this repository.

For usage questions, configuration help, or suspected bugs, search existing
[issues](https://github.com/dguptawolveflake/wolvekafka/issues) and open a new
issue if needed. Include the WKS version or commit, deployment environment,
sanitized configuration, what happened, what you expected, and minimal
reproduction steps. The [quickstart](README.md#five-minute-quickstart),
[delivery/security guide](docs/delivery-and-security.md), and
[Helm guide](services/wks/README.md) may answer common setup questions.

For feature proposals, describe the use case and why the existing Kafka →
HTTP handler → optional Kafka output path does not meet it. The
[roadmap](ROADMAP.md) lists current priorities, not guaranteed delivery dates.

Do not post secrets, credentials, or private customer data. For a vulnerability
or a code-of-conduct report, use the private contact in [SECURITY.md](SECURITY.md)
instead of an issue.
