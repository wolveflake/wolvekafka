Strimzi Kafka cluster "{{ .Values.clusterName }}" is being deployed.

The Strimzi operator will reconcile the Kafka CR and create the broker pods.

Wait for the cluster to become ready:

  kubectl wait kafka/{{ .Values.clusterName }} \
    --for=condition=Ready \
    --timeout=300s \
    -n {{ .Release.Namespace }}

Once ready, the internal bootstrap address is:

  {{ .Values.clusterName }}-kafka-bootstrap.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.kafka.listeners.plain.port }}

Quick test — produce and consume:

  kubectl -n {{ .Release.Namespace }} run kafka-producer -ti \
    --image=quay.io/strimzi/kafka:0.51.0-kafka-{{ .Values.kafka.version }} \
    --rm=true --restart=Never \
    -- bin/kafka-console-producer.sh \
       --bootstrap-server {{ .Values.clusterName }}-kafka-bootstrap:{{ .Values.kafka.listeners.plain.port }} \
       --topic test

  kubectl -n {{ .Release.Namespace }} run kafka-consumer -ti \
    --image=quay.io/strimzi/kafka:0.51.0-kafka-{{ .Values.kafka.version }} \
    --rm=true --restart=Never \
    -- bin/kafka-console-consumer.sh \
       --bootstrap-server {{ .Values.clusterName }}-kafka-bootstrap:{{ .Values.kafka.listeners.plain.port }} \
       --topic test --from-beginning
